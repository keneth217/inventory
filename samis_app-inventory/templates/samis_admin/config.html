Installation Guide
How to Install and Configure the Samis School Management System
Server Requirements

The System Should be installed on a server with the following requirements

    Ubuntu 22.04 LTS Server
    4 CPU Cores
    8 GB RAM
    200 GB SSD Storage
    Python 3.10 (recommended) or higher
Install Packages

The following packages are required and should thus be installed with the commands provided

    sudo apt-get update
    sudo apt-get install python3-pip python3-dev build-essential libssl-dev libffi-dev python3-setuptools
    sudo apt-get install nginx postgresql libpq-dev sqlite3 unzip
Python Modules

The following Python3 modules are required. Run the commands to provided to install them.

    pip3 install psycopg2-binary gunicorn
    pip3 install flask flask_sqlalchemy flask-bcrypt flask_httpauth
    pip3 install fuzzywuzzy apscheduler sendgrid psutil pyarmor pyyaml
Web Server Installation

Using the samis.zip file provided. Run the following commands to install the web server

    sudo useradd -m samis
    sudo mkdir /opt/SAMIS_STOCK-APP
    sudo cp samis.zip /opt/SAMIS_STOCK-APP
    cd /opt/SAMIS_STOCK-APP
    sudo unzip samis.zip
    sudo cp samis_stock.service /etc/systemd/system/
    sudo cp samis_stock /etc/nginx/sites-available/
    sudo chown -R samis:samis /opt/SAMIS_STOCK-APP
    sudo systemctl start samis_stock
    sudo systemctl enable samis_stock
    sudo systemctl restart samis_stock
    sudo systemctl status samis_stock
    sudo ln -s /etc/nginx/sites-available/samis_stock /etc/nginx/sites-enabled
    sudo nginx -t
    sudo systemctl restart nginx
Configure SSL

The following commands install a letsencrypt certificate to secure the web server

    sudo snap install core
    sudo snap refresh core
    sudo apt remove certbot
    sudo snap install --classic certbot
    sudo ln -s /snap/bin/certbot /usr/bin/certbot
    sudo certbot --nginx -d samislive.ujuzi.africa
    sudo systemctl status snap.certbot.renew.service
    sudo certbot renew --dry-run
Database Configure

The following commands setup and configure your Postgresql database

    sudo -i -u postgres
    psql
    ALTER USER postgres PASSWORD 'NEW_DB_PASSWORD';
    CREATE DATABASE samis_data;
    \q
    exit

Edit the file settings.yaml with the actual server data

Run Web Application

The following commands configure and start the web application

    cd /opt/SAMIS_STOCK-APP
    python3 configure.py
    systemctl restart nginx
    systemctl restart samis_stock

Visit the server address to access the application

Login as Super Administrator and configure the system as may be required
