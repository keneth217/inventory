System User Guide
Learn how to use the Samis Inventory Management System
Users and Departments

On the side menu, Select Departments

Here you can perform the following operations

    View all departments
    View number of employees in each department
    View number of assets in each department
    Create new department
    Add a new user to a department

Select one department to view its data

Here you can perform the following operations

    View all employees in the department
    View all assets in the department
    Edit department details
    Request for stock and assets for the department

Select one employee to view their data

Here you can perform the following operations

    View all employee details
    Edit employee details
    View all assets assigned to the employee
Stores, Units and Products

On the side menu, Select Inventory

Here you can perform the following operations

    View all products and quantities in stock
    Create new product measuring units
    Create new products
    Add stock items for each product

Select one product to view its data

Here you can perform the following operations

    View all the stores
    Create new store

Select one store to view its data

Here you can perform the following operations

    View all products and quantities in the store
    Edit store details
    Add stock to the store
    Move stock to another store
    Record loss of stock
Assets

On the side menu, Select Asset Regfster

Here you can perform the following operations

    View all the assets in the register
    Create a new asset type e.g. Computers
    Create a new asset
Suppliers

On the side menu, Select Purchase Orders, then Suppliers

Here you can perform the following operations

    View all your suppliers
    Create a new supplier

Select one supplier to view their details

Here you can perform the following operations

    View the supplier's details
    View the orders the supplier has supplied
    Edit the supplier's details
