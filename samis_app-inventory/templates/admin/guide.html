System Administration Guide
How to Configure and Manage the Samis School Management System
System Data

On the side menu, Select Admin -> Settings

Here you can view a list the following data items and their count

    Departments
    Employees
    {%if session.module == "Inventory"%} Suppliers
    Units
    Stores
    Products
    {%else%} Terms
    {%endif%}

Select one data item e.g. Departments

Here you can perform the following operations

    View all items (Departments)
    Add new item (Department)
    Delete one item (Department)
School Data

On the side menu, Select Admin -> Settings

Here you can view and edit the following data

    School Logo (Upload)
    School Name
    School Address
    Name of current user
System Users

On the side menu, Select Admin -> Users

Here you can perform the following operations

    View all the system users
    Create new system user
    View the user logs for a selected user
    Name of current user
Deleted Items

On the side menu, Select Admin -> Deleted Items

Here you can perform the following operations

    View all the deleted items in the system
    Restore an erroneously deleted item
User Logs

On the side menu, Select Admin -> User Logs

Here you can perform the following operations

    View all the system user logs
    Filter logs by any field
    View the logs for one user
