Installation Guide

Copy the installation files to the INSTALL folder

Download and Install Python 3.10.0; you can get it here.

    Downloaded file: python-3.10.0-amd64.exe

Select one department to view its data

Open the command prompt

    Windows KEY + R
    Type CMD and ENTER

CD to the INSTALL folder

Run the following commands

    py -m pip install --upgrade pip
    py -m pip install -r requirements.txt
    py configure_stock.py
    py samis_stock .py

Open the application on your browser; you can open it here.

    http://localhost:6800

NB: You can also install the app in a virtual environment
