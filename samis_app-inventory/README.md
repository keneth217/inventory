# samis_app
School Management System

This is a demo of the Inventory module for Windows

# Installation Guide
1. Install python-3.10.0-amd64.exe from: https://www.python.org/ftp/python/3.10.0/python-3.10.0-amd64.exe

2. Open the command prompt

3. CD to the folder with the install files

4. Run the following commands:
  
    py -m pip install --upgrade pip
  
    py -m pip install -r requirements.txt 

    py configure_stock.py
  
    py samis_stock.py

6. Go to http://localhost:6800 on your browser

7. Login using the default email and password for Samis Super Admin

NB: The SMS Gateway has been de-activated for testing purposes You can also install the app in a virtual environment
